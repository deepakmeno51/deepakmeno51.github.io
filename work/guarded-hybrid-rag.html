Guarded Hybrid RAG

Retrieval-augmented generation that combines keyword and vector search, with guardrails on input and output.

System architecture

[Query] --> [Input guard] --> [Hybrid retriever: keyword + vector] --> [LLM] --> [Output guard] --> [Answer]

Pipeline

  1. Ingest and chunk documents
  2. Index for keyword and vector search
  3. Screen the query
  4. Retrieve and rerank
  5. Generate a grounded answer
  6. Check the output before returning it
